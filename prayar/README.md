# مواقيت الصلاة (Prayer Times App)

تطبيق React لعرض مواقيت الصلاة في المدن المصرية المختلفة.

## الميزات

- عرض مواقيت الصلاة الخمسة
- اختيار المدينة من قائمة المدن المصرية
- عرض التاريخ الحالي
- تصميم responsive للهواتف المحمولة
- استخدام API Aladhan للحصول على المواقيت الدقيقة

## التثبيت والتشغيل

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```

## النشر

التطبيق منشور على GitHub Pages: https://mohamedfrontenddev-byte.github.io/Prayar-App/

## التقنيات المستخدمة

- React 19
- Vite
- CSS3
- Aladhan API
